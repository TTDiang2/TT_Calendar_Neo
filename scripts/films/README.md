# 「代码即影片」宣传片工坊 —— Agent 交接手册

> 给下一个做视频的 Agent：这套管线在 TT 日历项目里从零跑通并交付过两轮成片
> （v1 单功能 36s 被否 → v2 全功能 51s 过审），本文是全部经验教训的浓缩。
> 先读「哲学」定预期，再照「QA 协议」保质量，踩坑速查表放最后。

## 0. 哲学与适用边界

**代码即影片**：零视频生成模型、零素材库，每一帧由代码确定性渲染，配乐由代码合成。
优势：改文案/换语言/调节奏零成本重渲；每帧可复现、可 diff、可回归。
不适用：3D 场景、手绘笔触、真实镜头语言（景深/运镜模糊）——这些需要 WebGL/生成模型。
产品宣传片的铁律：**真实 UI 截图为骨架，代码动效只做包装**。绝不手绘假 UI 元素与真图同屏
（我们画过一堵假热力墙和真热力图同屏对比，廉价感爆炸，已删）。

## 1. 工具链（本机已验证）

| 环节 | 工具 | 要点 |
|---|---|---|
| 逐帧渲染 | **Python + Pillow** | 形状/文字/模糊全够用；不要用浏览器截图（IAB fullPage 内容按视口重复、单帧 2.3s 太慢、READY 轮询不可靠） |
| 合成 | **ffmpeg rawvideo 管道** | `Popen(['ffmpeg','-f','rawvideo','-pix_fmt','rgb24','-s',WxH,'-r','30','-i','-','-i',wav,...])`，stdin 直写 `img.convert('RGB').tobytes()`；`-movflags +faststart` |
| 配乐 | **Node 手写合成器** → WAV 16bit | 振荡器+包络+混响+母带全套可代码化，见 film_music2.mjs |
| 中文字体 | `C:/Windows/Fonts/msyhbd.ttc`(标题) `msyh.ttc`(正文) `simkai.ttf`(诗意句) | 楷体做情绪句、黑体做信息句 |
| 质检 | Pillow 逐帧差分 + contact sheet | 见 §4，这是最值钱的一节 |

## 2. 架构：引擎与影片严格分离

```
film_engine.py   能力层：缓动族/Track/精灵缓存/纸纹/水墨/手机框/图标/颗粒暗角
film_vertical2.py 时间轴层：幕次划分/构图坐标/时间常数（只写「什么时刻什么在哪」）
film_music2.mjs  配乐层：BPM/和声进行/编曲结构/音效对位
```

- **关键帧**：`Track([(t0,v0),(t1,v1,ease)])`；缓动族 `outq`(淡入) `outback`(开花回弹)
  `outelastic`(上色弹性) `inq`(退场)。弹性动画只用于「出现」，退场永远用平滑 outq。
- **精灵缓存**：重复元素（文字/染色格/手机框）按 key 缓存 3-4 倍超采样降采样图。
  两条铁律，都是血泪：
  1. **key 必须含全部语义维度**。pframe 缓存 key 只写了宽度漏了截图路径 → 同宽度三幕
     全部复用第一幕的图（「十二个月」配月历）。审查方法：问自己"这个 key 相同时，
     渲染结果一定相同吗？"
  2. **缓存对象返回后绝不可原地修改**。`cache.putalpha()` 原地衰减 → 背景每 0.4s 亮暗
     一次（用户直接看出来的闪烁）。修法：alpha/变换在 maker 里预乘完成。
- **性能预算**：≤0.4s/帧（51s×30fps≈7 分钟/片）。手法：blur 类图层按 1/4 分辨率渲染
  再放大；缓变层量化缓存但**必须预乘**；文字缩放用 BILINEAR 缓存到 0.01 步长；
  全屏贴片（颗粒/暗角）预合成 RGBA 只做 composite。

## 3. 内容方法论：怎么「全面」展示一个产品

1. **先盘点素材再写脚本**：把真机截图/组件裁片全部列出来（`ls device/ crops/`），
   每张能讲什么功能写下来。功能清单 > 幕次清单 > 时间轴，顺序不能反。
2. **一功能一幕，5-7 秒**：v2 十幕 = 钩子 → 染色月历 → 年视图 → 待办三视图连切 →
   提醒/重复 → 倒数日 → 数据洞察 → 小组件 → 差异化快闪 → 品牌收束。
   "三视图连切"这类同功能多形态用 3s/段快切 + 统一 stamp 动效串联。
3. **每幕三件套**：功能截图（手机框）+ 一句价值主张（大字）+ 一句机制说明（小字）。
   文案先写"用户得到什么"再写"怎么实现的"。
4. **差异化收尾用快闪行**：图标点 + 短语（一键搬家/8 语言/无广告），每条 0.7s。
5. **节拍对齐**：先定 BPM（76-92），画面大动作（开花/翻牌/幕切）落在小节线和小节首拍，
   音效（whoosh/tick/sparkle）严格对位画面事件。配乐结构按幕次编曲（intro→build→full→
   half→back→out），见 film_music2.mjs 的 T_BEAT/T_FULL 常量。
6. **诚实的音色边界**：纯合成配乐=结构完整但音色朴素。客户若要高级感：Suno/免版权库
   出一轨替换，画面管线不动，卡点重渲 5 分钟。给替换留好「幕次-小节对照表」。

## 4. QA 协议（按顺序执行，缺一步都会翻车）

```python
# ① 崩帧全扫：0.25s 步进（动画中间态最容易炸：PIL rounded_rectangle 的
#    radius 边界 off-by-one 只在特定尺寸组合触发——radius 必须 clamp 到 (边长-2)//2）
t = 0
while t < DUR:
    frame(round(t, 3)); t += 0.25

# ② contact sheet：0.85s 步进全片拼 8 列网格缩略图，逐格目检
#    专抓：文字重叠 / 错图 / 溢出屏幕 / 残影 / 浮层糊脸
#    （单点抽帧会漏——我们 10 个"完成态"QA 帧全绿，contact sheet 一眼看出 8 处穿帮）

# ③ 闪烁检测：逐帧差分三件套
#    same-frame diff 必须 == 0（非确定性=缓存被原地改/隐藏随机源）
#    quantum 边界 diff（量化缓存的段边界）应 < 0.5 灰度
#    consecutive diff 只允许来自刻意设计的颗粒（alpha ≤ 6）
#    ffmpeg 抽帧验证时必须单输入单输出，多输入的 -ss 映射会抽错帧（假警报教训）

# ④ 成片终检：ffprobe 时长/规格 + 从 mp4 抽帧（不是从 frame() 函数！）目检
```

## 5. 坑速查表（每一行都真实踩过）

| 症状 | 根因 | 修法 |
|---|---|---|
| 背景周期性闪烁 | 缓存对象被 putalpha 原地修改 | 变换在 maker 内预乘 |
| 多幕显示同一张图 | 缓存 key 漏语义维度（path） | key 补全 |
| 文字糊成一团 | 动态公式算坐标（sin 布局） | 改等距固定网格，间距 ≥ 元素宽 |
| 手机框四角露白 | 层序错误（截图直角贴入+反相蒙版涂白） | 深色机身→圆角裁剪截图→贴入 |
| 偶发 x1<=x0 崩溃 | PIL 圆角矩形 radius 边界 | `radius = min(r, (边长-2)//2)` |
| 幕切换两机叠影 | 幕次硬截断无退场 | 每幕乘 `fade_out(t, t_end-0.3)` |
| 全片渲染 40 分钟+ | 每帧全量重渲模糊层 | 1/4 分辨率放大 + 量化缓存预乘 |
| 音画不对拍 | 先做画面后定音乐 | 先锁 BPM 和幕次小节表，再编曲 |
| 相对路径 EOF 崩 | 后台任务 cwd 漂移 | 脚本内基于 `__file__` 解析绝对路径 |
| __pycache__ 入库 | git add 目录 | .gitignore 补 `__pycache__/` |
