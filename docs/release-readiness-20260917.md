## 1.4-4 卖点与目标用户画像

核心卖点排序（按说服力）：
1. **一次买断/便宜订阅，无订阅绑架**——对标全员 $30-70/年 的竞品，价格叙事清晰；
2. **本地优先 + 自有 GitHub 私库同步 + 无账号**——隐私是真实卖点（V2EX/即刻/HN 人群强共鸣），但注意大众用户会担心「换机迁移」，上架时需做好文档与导出；
3. **点涂视觉 + 打卡热力**——与 GitHub 贡献图同构的心智，打卡/自律人群（含 ADHD 人群）易传播；
4. **桌面端自定义订阅插件**——进阶卖点，营销上作为「极客向」补充，不作为主打。

目标用户画像：25-40 岁知识工作者、大学生、自律/打卡人群、ADHD 人群、自由职业者；Apple 生态占比高。获客渠道：国内**小红书**（效率内容主阵地，独立开发者话题阅读 5 亿+）、**即刻**（开发者圈层冷启动）；出海 **Product Hunt** 标配，V2EX/B站 辅助。

## 1.4-5 定价建议

品类教训：纯买断（Sorted3）后续更新乏力口碑下滑；Morgen 取消免费档遭反弹；成功样板是 Things 3（纯买断长青）与 Structured（freemium+双轨）。

**推荐方案（Structured 模式）**：
- 免费档：日历 + 点点 + 基础打卡 + 本地存储（拉新基本盘，本地存储成本≈0）；
- Pro 订阅：**国区 ¥68/年（合 ¥8/月）｜美区 $9.99/年**——约为 TickTick 一半，留促销空间；
- 终身买断：**国区 ¥98（首发 ¥68）｜美区 $29.99（首发 $19.99）**——承接订阅疲劳人群，2-3 年回本于订阅；
- 小型开发者计划抽成 15%（国区 2026-03 起 12%），成本结构支撑低价。

备选方案（验证期）：iOS 纯买断 国区 ¥30 / 美区 $9.99，先跑量验证留存，再转推荐方案。

## 1.4-6 上架国区 vs 外区

- **国区强制 ICP/APP 备案**：2024-03-31 起无备案号即从国区下架（工信部 2023 新规）。备案需大陆服务器 + 大陆主体，个人身份证可办，周期约 2-4 周（不确定）。
- 分成：**2026-03-15 起 Apple 下调国区分成**（标准 25%、小型计划 12%），承诺不高于其他市场；美区维持 30%/15%。
- 日历/效率类非强监管类目（不像游戏要版号），国区敏感点主要是隐私合规与备案号展示。
- **建议：先上外区（美区+全球，排除中国）**——零备案门槛、当天可发；同步在办备案，备好后补国区。若核心用户在国内，国区 12% 抽成 + 买断心智反而更划算，值得补备案。

## 1.4-7 法律风险

1. **功能模仿**：「日历+待办」是通用功能组合，著作权只保护代码与视觉表达、不保护功能思想；未检索到可主张该组合的专利（不确定，未做专利穷尽检索）。红线：勿抄代码/图标/名称；勿逐像素仿苹果原生日历 UI（App Store 2.3.1 抄袭条款的拒审风险大于诉讼风险）。
2. **数据合规**：纯本地存储 → 隐私标签可填「未收集数据」，GDPR/《个保法》义务最小；仍需准备一份隐私政策（声明数据不出设备）。GitHub 同步功能涉及用户数据出境（存于美国服务器），需在政策中披露。
3. **GitHub 做同步后端**：ToS 未禁止私有仓存 JSON，私有仓内容保密；但官方表态「纯当云存储不受鼓励」，且有 API 频率限制——灰色但普遍可行。建议：文档标注「实验性功能」，并准备 WebDAV 等备选通道（未来工作）。
4. **订阅第三方财经日历**（英为财情/集思录）：事件日期本身是事实不受版权保护，但**整站抓取再展示**有《反不正当竞争法》第 2/12 条风险（大众点评诉百度等判例确立「公开数据≠可自由商用」）。**我们手机端不上订阅功能**的决定在法律上是对的；桌面端插件由用户自行配置订阅源、数据存本地，风险由用户行为承担的模式也相对安全。建议：内置源只保留一手来源（交易所/政府节假日），并展示数据来源署名。
