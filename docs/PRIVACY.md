# TT 日历 隐私政策

**最后更新：2026-09-21**

TT 日历（以下简称"本应用"）是一款个人日历与待办管理应用。我们（开发者，TTDiang2）在设计中遵循"数据归你"的原则，本政策说明本应用处理哪些信息、如何处理、以及你的权利。

## 一、我们不收集任何数据

本应用**不收集、不上传、不出售**任何个人数据：

- 不含广告 SDK、不嵌入任何第三方统计/追踪组件
- 不请求或记录你的位置、通讯录、照片、健康数据
- 不注册账号，不建立用户档案

## 二、数据的存储位置

1. **本地存储**：你的全部数据（日历事件、日程、待办、倒数日、涂色标记、配置）保存在**你自己的设备本地**（SQLite 数据库 + 应用沙盒），离线可完整使用。
2. **小组件**：主屏小组件所需的数据快照保存在设备本地的 App Group 共享容器中，仅本设备的小组件扩展可读取。

## 三、唯一可选的数据传输：你自己的 GitHub 仓库

若你主动开启"数据同步"功能，本应用会把你的数据与你**自己注册的 GitHub 私有仓库**进行同步：

- 同步目标是**你拥有并控制**的仓库，开发者无法访问
- 认证使用你本人生成的 GitHub Personal Access Token（PAT），该 Token 仅保存在你设备本地，**永不上传给开发者或任何第三方**
- 你可随时在设置中停用同步、删除 Token，或直接删除该仓库

若你不开启同步，本应用不产生任何网络数据传输（仅在检查可更新订阅源等你显式配置的功能时，向**你指定**的地址发起请求）。

## 四、权限说明

- **通知**：仅在你设置闹钟/每日提醒后，用于弹出本地通知
- **本地网络**（可选）：仅当你把应用连接到同一局域网内的电脑数据服务时使用

## 五、儿童隐私

本应用不面向儿童收集任何信息，也不包含任何用户生成内容的公开分享功能。

## 六、你的权利与数据删除

- 设备内数据：卸载应用即彻底删除
- 同步数据：删除你 GitHub 上的同步仓库即可彻底删除
- 我们没有任何服务器，因此无需也无法替你"注销"

## 七、政策变更

重大变更将通过应用内公告或本页面更新告知。
