## 5. 附：本项目已解决的 iOS 构建坑（与前几轮调试相关）

| 坑 | 原因 | 解法（已落地） |
|---|---|---|
| Xcode 打不开工程（format 77） | tauri 2.11 生成 Xcode 16 格式，macos-14 是 Xcode 15.4 | runner 换 `macos-15` |
| `pnpm install` 崩：ERR_PNPM_ABORTED_REMOVE_MODULES_DIR_NO_TTY | pnpm 11 在 build 前复检依赖想清理 node_modules，非交互环境直接中止 | **写进 `~/.npmrc`（global）**：`confirm-modules-purge=false`、`verify-deps-before-run=false` |
| 真机构建崩：`server-addr` 读不到 | 绕过 tauri 手搓 xcodebuild，触发了 dev 专用的 xcode-script | 用官方 `tauri ios build`，别手搓 |
| 打出 296 字节空 .ipa | 脚本 `xcodebuild \| tail` 吞掉真实退出码，误把失败当成功 | 严格取退出码 + 校验 .app 内有可执行文件 |

**pnpm 那条特别注意**：Xcode 的 build phase **不继承** CI 的 `env:`，而 pnpm **不向上递归**查找 `.npmrc`（只读当前目录和 `~/.npmrc`）→ 仓库根的 `.npmrc` 对 build phase 无效，**必须写 global**。本仓库已在 CI 与 Mac 脚本里用 `pnpm config set --global ...` 处理。
